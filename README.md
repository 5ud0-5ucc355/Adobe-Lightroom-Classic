# Lightroom Classic Knowledge Base

A structured personal reference guide for managing, merging, and maintaining catalogs in Adobe Lightroom Classic.

This repository documents workflows, troubleshooting steps, and best practices for maintaining a clean and scalable photo library system.

---

## 📌 Purpose

This project is designed to:
- Consolidate multiple Lightroom catalogs into a single workflow
- Manage external drives and file paths effectively
- Prevent data loss, duplication, and broken links
- Build a long-term Lightroom organization system

## 🧠 Core Workflow

The primary process covered in this repository:

1. Select a master catalog
2. Import older catalogs into it
3. Manage file paths across external drives
4. Resolve missing files and duplicates
5. Optimize and back up final catalog

---

## 💾 Key Concepts

- **Catalogs** store edits and organization, not image files
- **External drives** hold the actual photos
- Lightroom relies on **file paths**, not embedded storage
- Merging catalogs requires careful handling of:
  - Metadata
  - Develop edits
  - Folder structure

---

## ⚠️ Important Notes

- Always back up catalogs before merging
- Avoid moving files outside Lightroom
- Ensure external drives are connected before importing catalogs
- Use one master catalog whenever possible
